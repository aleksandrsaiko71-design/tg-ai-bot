# Telegram AI-бот, который работает 24/7

Личный AI-собеседник в Telegram: отвечает на любые вопросы, помнит контекст диалога
и живёт на сервере — ноутбук можно выключать.

Написан на Python (aiogram 3), работает с любым OpenAI-совместимым API:
OpenAI, OpenRouter (есть бесплатные модели), DeepSeek, Google Gemini и другие.

Без AI-ключа бот всё равно отвечает — через бесплатный демо-сервис (медленно, 1 ответ
в ~45 секунд). Для быстрого и приватного общения добавьте свой ключ — это 2 минуты.

## Что умеет

- Общается как обычный чат-бот: текст → ответ AI, с памятью последних сообщений.
- Работает без ключа в демо-режиме (с паузой из-за бесплатного лимита).
- `/reset` или кнопка «🔄 Новый диалог» — начать разговор с чистого листа.
- `/help` — подсказка по командам.
- Делит длинные ответы на несколько сообщений (лимит Telegram — 4096 символов).
- Показывает «печатает…», пока модель думает, и не даёт запустить два ответа сразу.
- Понятно объясняет ошибки: неверный ключ, лимит запросов, таймаут.
- Проверка здоровья `/healthz` — для хостинга и мониторинга.
- Работает в двух режимах: `polling` локально и `webhook` на сервере (переключается сам).

## Шаг 1. Токен бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумайте имя и username (должен заканчиваться на `bot`).
3. Скопируйте токен вида `123456789:AAHdqTcv...` — он понадобится дальше.
4. Там же можно задать описание и аватарку: `/setdescription`, `/setuserpic`.

Никому не показывайте токен. Если он утёк — `/revoke` в BotFather.

## Шаг 2. Ключ AI-провайдера (можно пропустить)

Без ключа бот запустится в демо-режиме: бесплатный внешний сервис отвечает
примерно раз в 45 секунд и видит ваши сообщения. Для нормального общения
лучше добавить свой ключ — выберите любой вариант.

| Провайдер | `AI_BASE_URL` | Пример `AI_MODEL` | Цена |
|---|---|---|---|
| **OpenRouter** (рекомендую для старта) | `https://openrouter.ai/api/v1` | любая модель с суффиксом `:free`, см. [каталог](https://openrouter.ai/models?max_price=0) | бесплатные модели — $0 |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` или `gpt-4.1-mini` | платно, центы за диалоги |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | очень дешёво |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta/openai` | `gemini-2.0-flash` | есть бесплатный лимит |

Где взять ключ:

- OpenRouter — [openrouter.ai/keys](https://openrouter.ai/keys), регистрация по email/GitHub.
- OpenAI — [platform.openai.com/api-keys](https://platform.openai.com/api-keys).
- DeepSeek — [platform.deepseek.com](https://platform.deepseek.com).
- Gemini — [aistudio.google.com/apikey](https://aistudio.google.com/apikey).

> Важно: `AI_BASE_URL` должен указывать на корень API (обычно с `/v1` в конце),
> бот сам добавит `/chat/completions`. Название модели должно точно совпадать с каталогом провайдера.

## Шаг 3. Проверка на ноутбуке

Нужен Python 3.10+ (у вас 3.11 — подходит). Одна команда в PowerShell:

```powershell
cd "C:\Users\Honor\Documents\Default Project\tg-ai-bot"
.\start.ps1
```

Скрипт сам создаст окружение, поставит зависимости, откроет `.env` в Блокноте
и запустит бота. Вставьте токен в строку `BOT_TOKEN=`, сохраните и закройте Блокнот.
`AI_API_KEY` можно пока оставить пустым — бот ответит в демо-режиме.

Остановить — `Ctrl+C`. Следующие запуски — снова `.\start.ps1`.

Если PowerShell запрещает запуск скриптов:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

Ручной вариант:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
python bot.py
```

В логе появится `Бот @ваш_бот готов`. Откройте бота в Telegram, нажмите «Start» и напишите сообщение.

Быстрая самопроверка без Telegram:

```powershell
python tests/test_smoke.py
```

Если `pip` ругается на SSL-сертификат (бывает из-за антивируса/корпоративной сети),
`start.ps1` уже обходит это через `--trusted-host`. Вручную:

```powershell
python -m pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org -r requirements.txt
```

## Шаг 5. Деплой на Render (бот работает без вашего ПК)

1. Зарегистрируйтесь на [render.com](https://render.com) через GitHub.
2. **New → Blueprint** → выберите репозиторий `tg-ai-bot`.
3. Render найдёт `render.yaml` и предложит создать web-сервис. Нажмите **Apply**.
4. В открывшейся форме введите `BOT_TOKEN` — токен из BotFather.
   `AI_API_KEY` добавлять не обязательно: без него включится демо-режим.
5. Дождитесь статуса **Live** (первый билд 2–5 минут) и откройте **Logs**.

В логах должно быть:

```
Webhook зарегистрирован в Telegram: https://tg-ai-bot-xxxx.onrender.com/webhook
Бот @ваш_бот готов. Модель: ...
```

Теперь пишите боту в Telegram — ноутбук можно выключать.

Адрес сервиса Render сообщает через переменную `RENDER_EXTERNAL_URL`, поэтому webhook
включается автоматически, а `PORT` и HTTPS Render настраивает сам.

### Чтобы бесплатный сервис не засыпал

На free-плане Render останавливает сервис после 15 минут без входящего трафика.
Telegram «разбудит» его только следующим сообщением, и первый ответ придёт с задержкой
30–60 секунд. Лечится бесплатным пингом:

1. [uptimerobot.com](https://uptimerobot.com) → **Add New Monitor**.
2. Type: `HTTP(s)`, URL: `https://ВАШ-СЕРВИС.onrender.com/healthz`.
3. Interval: `5 minutes`.

Пинг раз в 5 минут не даёт Render усыпить сервис. Месячный лимит free-плана —
750 часов, а в месяце ~730, так что один сервис вписывается в бесплатный тариф.
Если Render всё же попросит карту или лимиты изменятся — тот же код работает на
Koyeb, Fly.io или любом VPS.

### Свой VPS (альтернатива)

```bash
git clone https://github.com/ВАШ_ЛОГИН/tg-ai-bot.git
cd tg-ai-bot
cp .env.example .env && nano .env        # BOT_TOKEN, AI_API_KEY и WEBHOOK_BASE_URL=https://ваш-домен
docker build -t tg-ai-bot .
docker run -d --restart=always --env-file .env -p 8080:8080 --name tg-ai-bot tg-ai-bot
```

Нужен HTTPS-домен, проксирующий на порт 8080 (Caddy/Nginx + Let's Encrypt),
и `WEBHOOK_BASE_URL=https://ваш-домен`. Либо запускайте без Docker в режиме polling:

```bash
python bot.py        # если WEBHOOK_BASE_URL не задан — polling
```

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| В логе `Не задан BOT_TOKEN` | Нет `.env` рядом с `bot.py` или переменная не добавлена в Render → Environment |
| `409 Conflict: terminated by other getUpdates request` | Бот уже запущен где-то ещё: остановите локальный `python bot.py` или удалите webhook |
| Бот молчит, ошибок нет | Проверьте `/healthz`; на Render посмотрите Logs и статус сервиса |
| Ответ «Ключ AI-провайдера неверный» | Проверьте `AI_API_KEY`, нет ли лишних пробелов |
| Ответ «Модель недоступна» | Неверное имя `AI_MODEL` или в `AI_BASE_URL` нет `/v1` |
| `429` / «провайдер перегружен» | Лимит бесплатной модели; подождите или смените модель |
| «Демо-режим перегружен» | Бесплатный сервис даёт 1 ответ в 45 секунд: подождите или добавьте `AI_API_KEY` |
| Ответ «AI-ключ ещё не добавлен» | `DEMO_AI=0` и пустой `AI_API_KEY` — либо добавьте ключ, либо уберите `DEMO_AI=0` |
| Первый ответ после простоя идёт минуту | Free-план Render уснул — настройте UptimeRobot (см. выше) |
| Долгий ответ, затем таймаут | Увеличьте `AI_TIMEOUT` (например, `120`) или выберите более быструю модель |

Локальный запуск при уже задеплоенном боте: polling-режим удалит webhook, и облачный бот
перестанет получать сообщения. После локальных тестов перезапустите сервис на Render,
чтобы webhook зарегистрировался снова.

## Ограничения и что дальше

- **История диалога хранится в памяти.** После перезапуска или засыпания сервиса контекст
  обнуляется. Для постоянной памяти замените `HistoryStore` в `storage.py` на SQLite/Redis
  (интерфейс: `get`, `append_many`, `reset`).
- **Только текст.** Фото и голосовые не распознаются — можно добавить Whisper/Vision.
- **Один AI-ответ за раз на пользователя** — защита от случайных дублей и лишних трат.
- **Приватность.** Сообщения уходят выбранному AI-провайдеру. В демо-режиме это публичный
  бесплатный сервис — не отправляйте туда пароли, документы и личные данные.
- **Стоимость.** Render free — $0. AI: бесплатные модели OpenRouter/Gemini — $0 в пределах лимитов,
  платные — обычно от нескольких центов за активный день общения.
